# За Гранью — VR-арена

Сайт VR-арены в чёрном, красном и электрическом синем стиле. Тексты, каталог игр, оборудование и тарифы обновлены по предоставленному ТЗ.

Сайт: https://Rusik2379.github.io/za-granyu-vr-arena/

## Страницы и возможности

- Главная, дни рождения, корпоративы и демонстрационная административная часть.
- Каталог с фильтрами и историями игр.
- Цены ПН–ЧТ и ПТ–ВС одновременно, собственная форма заявки вместо внешнего виджета.
- Шесть игр, пять видеообзоров и фотографии Quest 3 из предоставленных материалов.
- На главной три тарифа, включая праздник на 3 часа за 17 000 ₽ / 23 000 ₽.
- Увеличенный текст, плавное появление блоков с учётом сокращённого движения.
- Яндекс Карта для предварительного адреса: Барнаул, проспект Ленина, 100.
- Подпись и оригинальный логотип «Сибирь Софт» со ссылкой на sibsoft-it.ru в подвале.
- Обратная связь, отзывы, FAQ, статьи и пробное колесо скидок с именем и телефоном.
- Мобильная вёрстка и локальное сохранение заявок в браузере.

Контакты, отзывы и бонусные предложения тестовые. Игры и тарифы взяты из ТЗ. Цена часового праздника в ПТ–ВС не указана — отображается «Уточните у администратора». На главной, днях рождения и корпоративах используется собственная форма сайта. Без подключения серверного API BookNow она сохраняет тестовые заявки только в текущем браузере и не резервирует сеанс. Демо-админка открыта и предназначена только для вымышленных данных.

Колесо по умолчанию работает в пробном режиме. Отдельный серверный обработчик с SQLite, защитой от повторного участия и очередью доставки находится в `server/`. Он не включён в GitHub Pages и не подключён к BookNow. Подробности: [docs-integration.md](docs-integration.md).

Собственная форма онлайн-записи через API BookNow и открытие формы с бонусом после колеса подготовлены. Скрипты формы подключены к страницам; подключение аккаунта пока не выполнено. Запуск серверной версии и ограничения описаны в [docs-booknow.md](docs-booknow.md).

## Локальный запуск

Нужен Node.js. Внешние зависимости не требуются.

```sh
node serve.mjs
```

Откройте http://127.0.0.1:4175/.

## Публикация в GitHub Pages

Редактируйте исходные файлы в `dist/`. Затем подготовьте версию с путями для GitHub Pages:

```sh
node scripts/build-pages.mjs
```

Закоммитьте изменения в `dist/` и `docs/` и отправьте ветку `main` на GitHub. Pages публикует папку `docs/` из ветки `main` автоматически. `.nojekyll` отключает обработку готовых файлов через Jekyll.

Проверить именно собранную версию:

```sh
node serve.mjs --pages
```

Адрес: http://127.0.0.1:4174/za-granyu-vr-arena/.

Для другого имени репозитория задайте переменную `PAGES_BASE` (например, `/my-repo/`) перед сборкой и локальной проверкой.

## Проверки

```sh
node --check dist/app.js
node --check dist/promo.js
node --test server/promo.test.mjs
node scripts/build-pages.mjs
```

Сервер колеса и его тесты требуют Node.js 24+; статический сайт работает без Node.js в браузере.

## Собственная форма и BookNow

Внешний виджет Cue удалён со страниц. Кнопки бронирования снова открывают собственную форму с подстановкой формата, игры и длительности. Боковая кнопка колеса скрывается, пока посетитель просматривает раздел заявки.

`booknow-config.js` и `booking.js` подключены перед `app.js`. По умолчанию BookNow отключён. На статическом сервере и GitHub Pages форма остаётся демонстрационной. При подключении серверного обработчика используется каталог услуг и свободное время BookNow; ключ API остаётся только на сервере.

API BookNow поддерживает создание записи через `POST /bookings`. Проверенный сценарий: локации → услуги → свободные слоты → создание записи. Для живого подключения нужны ключ API, slug аккаунта, сопоставление услуг и проверка обязательных полей конкретного аккаунта. Подробности и ссылки: [docs-booknow.md](docs-booknow.md).
