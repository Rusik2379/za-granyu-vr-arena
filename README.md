# За Гранью — VR-арена

Сайт VR-арены в чёрном, красном и электрическом синем стиле. Тексты, каталог игр, оборудование и тарифы обновлены по предоставленному ТЗ.

Сайт: https://Rusik2379.github.io/za-granyu-vr-arena/

## Страницы и возможности

- Главная, дни рождения, корпоративы и демонстрационная административная часть.
- Каталог с фильтрами и историями игр.
- Цены ПН–ЧТ и ПТ–ВС одновременно, онлайн-запись через встроенный виджет Cue.
- Шесть игр, пять видеообзоров и фотографии Quest 3 из предоставленных материалов.
- На главной три тарифа, включая праздник на 3 часа за 17 000 ₽ / 23 000 ₽.
- Увеличенный текст, плавное появление блоков с учётом сокращённого движения.
- Яндекс Карта для предварительного адреса: Барнаул, проспект Ленина, 100.
- Подпись и оригинальный логотип «Сибирь Софт» со ссылкой на sibsoft-it.ru в подвале.
- Обратная связь, отзывы, FAQ, статьи и пробное колесо скидок с именем и телефоном.
- Мобильная вёрстка и локальное сохранение заявок в браузере.

Контакты, отзывы и бонусные предложения тестовые. Игры и тарифы взяты из ТЗ. Цена часового праздника в ПТ–ВС не указана — отображается «Уточните у администратора». Онлайн-запись на главной, днях рождения и корпоративах оформляется в Cue. Остальные демонстрационные формы сохраняют тестовые данные в браузере. Демо-админка открыта и предназначена только для вымышленных данных.

Колесо по умолчанию работает в пробном режиме. Отдельный серверный обработчик с SQLite, защитой от повторного участия и очередью доставки находится в `server/`. Он не включён в GitHub Pages и не подключён к BookNow. Подробности: [docs-integration.md](docs-integration.md).

Ранее подготовлена собственная форма онлайн-записи через API BookNow, а также открытие формы с бонусом после колеса. По поручению владельца подключение аккаунта отложено. Форма BookNow отключена от страниц сайта после перехода на Cue. Запуск серверной версии и ограничения описаны в [docs-booknow.md](docs-booknow.md).

## Локальный запуск

Нужен Node.js. Внешние зависимости не требуются.

```sh
node serve.mjs
```

Откройте http://127.0.0.1:4175/.

## Публикация в GitHub Pages

Редактируйте исходные файлы в `dist/`. Затем подготовьте версию с путями для GitHub Pages:

```sh
node scripts/build-pages.mjs
```

Закоммитьте изменения в `dist/` и `docs/` и отправьте ветку `main` на GitHub. Pages публикует папку `docs/` из ветки `main` автоматически. `.nojekyll` отключает обработку готовых файлов через Jekyll.

Проверить именно собранную версию:

```sh
node serve.mjs --pages
```

Адрес: http://127.0.0.1:4174/za-granyu-vr-arena/.

Для другого имени репозитория задайте переменную `PAGES_BASE` (например, `/my-repo/`) перед сборкой и локальной проверкой.

## Проверки

```sh
node --check dist/app.js
node --check dist/promo.js
node --test server/promo.test.mjs
node scripts/build-pages.mjs
```

Сервер колеса и его тесты требуют Node.js 24+; статический сайт работает без Node.js в браузере.

## Виджет Cue

Виджет аккаунта 4304, ID 19664, встроен вместо демонстрационной формы на главной и страницах мероприятий. Все кнопки бронирования ведут к одному виджету текущей страницы. Состояние выбранного сеанса сохраняется при повторном переходе к нему.

Настройки и загрузка находятся в `dist/cue-booking.js`, оформление обрамления — в `dist/cue-booking.css`. Используется официальный SDK версии 1.2.0. Тема задаётся и в URL iframe, и в SDK — акцент `#FF303D`, внешний фон `#10141E`, радиус 4 px. Внутренние карточки Cue остаются светлыми, поскольку SDK не предоставляет настройки их тёмной темы или пользовательского CSS.

Виджет загружается при приближении к разделу записи. SDK управляет высотой iframe и разворачиванием календаря. При ошибке доступны повторная загрузка и ссылка на отдельное окно. На время просмотра раздела записи боковая кнопка колеса скрывается, чтобы не перекрывать элементы виджета.

Предоставленный URL привязан к услуге «День за гранью (2 часа — арена + лаун зона. Выходные дни)». Пакет и цены определяются аккаунтом Cue. Соответствие остальных тарифов сайта потребует отдельных ссылок на виджеты или общего каталога от Cue. Выбор тарифа сайта не подставляется в виджет без подтверждённого параметра сервиса.

Колесо скидок пока работает в пробном режиме. Передача скидок или промокодов в Cue не настроена.
