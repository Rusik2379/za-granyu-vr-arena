# За Гранью — VR-арена

Сайт VR-арены в чёрном, красном и электрическом синем стиле. Тексты, контакты и тарифы обновлены по ТЗ и документу «Текст для сайта — 2». Список внесённых правок: [docs-word-revisions.md](docs-word-revisions.md).

Сайт: https://Rusik2379.github.io/za-granyu-vr-arena/

## Страницы и возможности

- Главная, все тарифы (`/prices/`), дни рождения, корпоративы и демонстрационная административная часть.
- Каталог с фильтрами и историями игр.
- Цены ПН–ЧТ и ПТ–ВС одновременно, собственная форма заявки вместо внешнего виджета.
- Шесть игр, пять видеообзоров и фотографии Quest 3 из предоставленных материалов.
- На главной четыре тарифа: открытая игра, закрытая арена на 1, 2 и 3 часа. Без лаунжа: 2 часа — 10 000 ₽ / 14 000 ₽, 3 часа — 15 000 ₽ / 20 000 ₽. Пакеты с лаунжем показаны отдельно.
- Увеличенный текст, плавное появление блоков с учётом сокращённого движения.
- Реальные телефон и адрес арены, Яндекс Карта, ссылки на сообщество VK и мессенджер MAX.
- Подпись и оригинальный логотип «Сибирь Софт» со ссылкой на sibsoft-it.ru в подвале.
- Обратная связь, отзывы, FAQ, статьи и колесо скидок с именем и телефоном.
- Мобильная вёрстка и локальное сохранение заявок в браузере.

Отзывы с отметкой «Пример отзыва» являются примерами. Контакты и тарифы взяты из материалов владельца. Цена часового праздника с лаунжем в ПТ–ВС не указана — отображается «Уточните у администратора». Используется собственная форма сайта без выбора сценария игры, с форматированием телефона `+7 9XX XXX-XX-XX`. Без серверного API BookNow она сохраняет тестовую заявку только в браузере и не резервирует сеанс. Демо-админка предназначена только для вымышленных данных.

На основном сервере колесо выдаёт один бонус на номер телефона. После выигрыша «Применить скидку к брони» открывает форму поверх сайта, подставляет имя, телефон и бонус. Сайт рассчитывает сумму со скидкой, сервер закрепляет бонус за бронью и сохраняет расчёт в примечании BookNow. Администратор применяет скидку к сумме заказа: публичный API не предоставляет изменения цены. На GitHub Pages колесо остаётся пробным.

На сервере `za-granyu22.ru` собственная форма подключена к BookNow: услуги, календарь ближайших 14 дней, свободные сеансы и создание бронирования. GitHub Pages сохраняет пробный режим. Запуск серверной версии и ограничения описаны в [docs-booknow.md](docs-booknow.md). Старый самостоятельный обработчик входящих заявок описан в [docs-integration.md](docs-integration.md).

## Локальный запуск

Нужен Node.js. Внешние зависимости не требуются.

```sh
node serve.mjs
```

Откройте http://127.0.0.1:4175/.

## Публикация в GitHub Pages

Редактируйте исходные файлы в `dist/`. Затем подготовьте версию с путями для GitHub Pages:

```sh
node scripts/build-pages.mjs
```

Закоммитьте изменения в `dist/` и `docs/` и отправьте ветку `main` на GitHub. Pages публикует папку `docs/` из ветки `main` автоматически. `.nojekyll` отключает обработку готовых файлов через Jekyll.

Проверить именно собранную версию:

```sh
node serve.mjs --pages
```

Адрес: http://127.0.0.1:4174/za-granyu-vr-arena/.

Для другого имени репозитория задайте переменную `PAGES_BASE` (например, `/my-repo/`) перед сборкой и локальной проверкой.

## Проверки

```sh
node --check dist/app.js
node --check dist/promo.js
node --test server/promo.test.mjs
node scripts/build-pages.mjs
```

Сервер колеса и его тесты требуют Node.js 24+; статический сайт работает без Node.js в браузере.

## Собственная форма и BookNow

Внешний виджет Cue удалён со страниц. Кнопки бронирования открывают собственную форму с подстановкой формата и длительности. Выбор сценария игры убран. Боковая кнопка колеса скрывается, пока посетитель просматривает раздел заявки.

`booknow-config.js` и `booking.js` подключены перед `app.js`. По умолчанию BookNow отключён. На статическом сервере и GitHub Pages форма остаётся демонстрационной. При подключении серверного обработчика используется каталог услуг и свободное время BookNow; ключ API остаётся только на сервере.

API BookNow поддерживает создание записи через `POST /bookings`. Проверенный сценарий: локации → услуги → свободные слоты → создание записи. Для живого подключения нужны ключ API, slug аккаунта, сопоставление услуг и проверка обязательных полей конкретного аккаунта. Подробности и ссылки: [docs-booknow.md](docs-booknow.md).
