# За Гранью — VR-арена

Демонстрационный сайт VR-арены в чёрном, красном и электрическом синем стиле. Включает новый логотип на прозрачном фоне.

Сайт: https://Rusik2379.github.io/za-granyu-vr-arena/

## Страницы и возможности

- Главная, дни рождения, корпоративы и демонстрационная административная часть.
- Каталог с фильтрами и историями игр.
- Тарифы будней и выходных, расчёт стоимости и демо-форма записи.
- Обратная связь, отзывы, FAQ, статьи и демо-рулетка.
- Мобильная вёрстка и локальное сохранение заявок в браузере.

Контакты, цены, игры, отзывы и предложения тестовые. Формы не резервируют сеанс и не отправляют письма. Демо-админка открыта и предназначена только для вымышленных данных. Серверная обработка, внешнее бронирование и Aktivator не подключены.

## Локальный запуск

Нужен Node.js. Внешние зависимости не требуются.

```sh
node serve.mjs
```

Откройте http://127.0.0.1:4175/.

## Публикация в GitHub Pages

Редактируйте исходные файлы в `dist/`. Затем подготовьте версию с путями для GitHub Pages:

```sh
node scripts/build-pages.mjs
```

Закоммитьте изменения в `dist/` и `docs/` и отправьте ветку `main` на GitHub. Pages публикует папку `docs/` из ветки `main` автоматически. `.nojekyll` отключает обработку готовых файлов через Jekyll.

Проверить именно собранную версию:

```sh
node serve.mjs --pages
```

Адрес: http://127.0.0.1:4174/za-granyu-vr-arena/.

Для другого имени репозитория задайте переменную `PAGES_BASE` (например, `/my-repo/`) перед сборкой и локальной проверкой.
